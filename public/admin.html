Setup tips
  • During setup choose Mixed Mode authentication and set a password for the sa login. PMO Hub signs in with a SQL login, not your Windows account.
  • Express turns TCP/IP off by default. Turn it on in SQL Server Configuration Manager → SQL Server Network Configuration → Protocols, then restart the SQL Server service.
  • A default Express install is a named instance, usually localhost\SQLEXPRESS. Named instances need the SQL Server Browser service running. Otherwise use localhost,1433 with the port you set.
  • For day-to-day use, create a dedicated login rather than using sa. It needs db_owner on the database, or the dbcreator role if PMO Hub should create the database.
