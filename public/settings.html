Where your data is kept

PMO Hub runs entirely in your browser. Entries and notes are saved in this browser on this device — there is no server and no sign-in. Clearing this site's data in the browser would remove them, so keep a backup file (below).

Backup file (recommended)

Pick a file — for example inside your OneDrive folder — and every change is also written there. On another device, point PMO Hub at the same file to carry on.

This browser can't keep a file up to date automatically (it needs Chrome or Edge, opened from https:// or http://localhost). Use Download / Restore below instead.
"Use an existing file" replaces what is in this browser with the file's contents.

Download / Restore

A complete copy of everything — entries, pins and notes — as one JSON file. Works in any browser.
